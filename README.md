# Sales Data Analysis Dashboard

## Skyrovix Internship - Task 1

This project focuses on analyzing Superstore sales data using Python
and creating a Sales Data Analysis Dashboard.

## Objective

- Clean and prepare the sales dataset
- Perform exploratory data analysis
- Analyze sales and profit performance
- Create meaningful visualizations
- Generate business insights

## Tools Used

- Python
- Pandas
- Matplotlib
- Google Colab

## Key Analysis

- Sales by Category
- Sales by Region
- Sales by Sub-Category
- Monthly Sales Trend
- Top Products
- Profit by Category
- Profit by Region
- Discount vs Profit
- Low-Profit Products

## Key Results

- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Total Orders: 5,009
- Total Customers: 793
- Total Quantity Sold: 37,873
- Profit Margin: 12.47%

## Business Insights

- Technology is the highest-selling category.
- West is the highest-selling region.
- Phones and Chairs are among the top-performing sub-categories.
- Profitability varies across products and categories.
- Discount levels should be monitored carefully because they can affect profitability.
